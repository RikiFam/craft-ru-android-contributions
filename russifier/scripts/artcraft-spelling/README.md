# Русская орфография в локальных сборках ArtCraft

Словарь встроен в Windows EXE и Android APK. Сеть и клавиатурный словарь Android не требуются. Имена программ, форматы файлов и содержимое документов при обновлении не переводятся и не меняются.

## Существующие проверки

WordCraft использует свой русский движок и встроенный запасной словарь. Пользовательский установленный словарь имеет приоритет. Для новых документов язык по умолчанию — русский; явно заданный язык сохраняется.

DeckCraft, GridCraft, DesignCraft и PhotoCraft проверяют русские слова через свои обычные окна орфографии, предлагают замены и сохраняют существующие механизмы редактирования и пользовательские словари.

## Новые проверки

В восьми остальных редакторах кнопка «Орфография · русский» открывает окно проверки: в Windows она внизу, на Android — наверху, вне системной панели Samsung. Окно показывает возможные ошибки и варианты замены. Нажатие на вариант **копирует исправленный текстовый фрагмент**, который нужно вставить в соответствующее поле. Проект автоматически не изменяется. После редактирования нажмите «Проверить заново».

| Редактор | Что проверяется |
|---|---|
| VectorCraft | Текстовые объекты документа |
| CADCraft | Однострочные и многострочные надписи пространства модели |
| FigCraft | Текстовые объекты макета |
| PdfCraft | Выделенный текст; сканы требуют предварительного распознавания |
| LightCraft | Названия, подписи и описания выбранных фотографий |
| FilmCraft | Субтитры, титры и текстовые сведения о материалах |
| EffectCraft | Текстовые слои активной композиции |
| SoundCraft | Названия и комментарии проекта, дорожек и маркеров |

Это проверка словарной орфографии, а не универсальная проверка грамматики. Специальные термины и имена могут отсутствовать в словаре. Новое окно ограничивает объём одним мегабайтом/2000 фрагментами/500 ошибками и сообщает о неполной проверке. Оно не распознаёт речь и не ищет текст внутри растровых изображений.

## Подготовка и проверка

На исходных локальных checkout с прежними переводами и Android-адаптацией:

1. `python scripts/artcraft-spelling/prepare.py`
2. `python scripts/artcraft-spelling/prepare_panels.py`
3. `python scripts/artcraft-spelling/prepare_tests.py`
4. `python scripts/artcraft-spelling/finish_sources.py`
5. `python scripts/artcraft-spelling/check.py regression wordcraft deckcraft designcraft photocraft` и `smoke_grid.py` для команд GridCraft (его прежний Unix-тест мешает собрать весь набор unit-тестов на Windows).
6. `cargo test --manifest-path scripts/artcraft-spelling/Cargo.toml --target-dir tmp/artcraft/spelling-panel-target` проверяет точные шаблоны общего окна и словаря один раз; они одинаковы во всех восьми новых окнах. `cargo clippy` с тем же manifest и `--all-targets -- -D warnings` проверяет этот модуль отдельно от прежних предупреждений редакторов.
7. Сборка Windows: `build_windows.py`; Android: прежние `scripts/artcraft-android/build*.ps1`.

Исходные словари, хеши и лицензия находятся в `scripts/artcraft-russian/dictionaries`. Уведомление об авторских правах доставляется вместе со сборками. Резервные копии до изменений — `tmp/artcraft/backups/before-russian-spelling`. Журналы сборок и проверок — `tmp/artcraft/spelling-builds`.
