# Обновление ArtCraft от 28 октября

Все 13 редакторов и ArtCraft Launcher обновлены на Windows и Samsung Galaxy
Tab S7+ (SM-T970, Android 13). Русский перевод перенесён на новые исходники;
новые подписи и подсказки вычитаны. Данные приложений и прежние значки сохранены.

| Приложение | Версия на обеих платформах |
| --- | --- |
| CADCraft | 0.14.0 |
| DeckCraft | 0.12.0 |
| DesignCraft | 0.14.0 |
| EffectCraft | 0.18.0 |
| FigCraft | 0.12.1 |
| FilmCraft | 0.14.0 |
| GridCraft | 0.13.0 |
| LightCraft | 0.15.0 |
| PdfCraft | 0.15.0 |
| PhotoCraft | 0.17.0 |
| SoundCraft | 0.14.0 |
| VectorCraft | 0.18.0 |
| WordCraft | 0.12.0 |
| ArtCraft Launcher | 0.9.0 |

Android-сборки имеют суффикс `-ru-android-preview3` и прежний ключ подписи.

- Старые переводы и Android-доработки сохранены в отдельных локальных ветках
  каждого исходного репозитория. Новые релизы и их SHA записаны в
  `update-2026-10-29.json`.
- Русские словари перенесены с сохранением новых строк разработчиков. Новые
  формулировки вычитаны в `update-translations-2026-10-29.json`.
- DeckCraft и SoundCraft заново обработаны из исходников новых тегов, включая
  файлы, выделенные разработчиками в отдельные модули.
- Android использует те же закреплённые версии egui/winit, что новые релизы.
  Имена пакетов, значки, рабочие папки и ключ подписи сохранены. Код версии — 3.
- Прежние APK и установленные EXE сохранены в
  `tmp/artcraft/backups/before-update-2026-10-29`.
- PhotoCraft 0.17.0 установлен на SM-T970. Проверены русский интерфейс,
  создание документа, рисование и сохранение PSD (215208 байт).
- Android-лаунчер 0.9.0 установлен; русский список приложений и значки проверены.
- Все 14 Android-пакетов обновлены поверх прежних установок, без удаления данных.
  Проверены версии через Android Package Manager и русские рабочие/стартовые окна.
  Подробности и хеши: `../artcraft-android/update-verification-2026-10-29.json`.
- PdfCraft открыл прежний тестовый PDF и отобразил пять интерактивных полей.
  В LightCraft исправлена пропущенная подпись в ленте фотографий; в VectorCraft
  вычитаны подсказки инструментов. Значки и ключ подписи APK сохранены.
- На Windows проверены запуск и русский интерфейс всех установленных редакторов,
  хеши исполняемых файлов, их версии и записи установок в реестре. Лаунчер
  больше не предлагает показанные на исходном снимке обновления.
  Доказательства: `windows-update-verification-2026-10-29.json`.
- MSI проверены по SHA256 и действительной подписи Learning Machines Inc
  перед установкой. Затем установлены собранные из исходников русские EXE.
- 26 тестов общего каталога craft-i18n и clippy прошли. Дополнительная сборка
  всего тестового модуля PhotoCraft UI остановлена до запуска тестов из-за
  длительной компиляции; результат этих тестов не заявляется как успешный.

Логи: `tmp/artcraft/<app>/update-build.log` для Windows,
`tmp/artcraft/android/<app>-update-build.log` для APK. Очереди записывают результаты
в `tmp/artcraft/update-build-results.json` и
`tmp/artcraft/android/update-build-results.json`. Итог Android с учётом
исправлений и повторных сборок: `tmp/artcraft/android/update-build-results-final.json`.

Таймер экрана планшета возвращён с временных 600000 на исходные 60000 мс;
значение прочитано обратно. Планшет оставлен с открытым русским лаунчером.

Проверки запуска не подтверждают все функции редакторов. Ограничения прежних
Android-портов (системные диалоги/интеграции, печать, мультимедиа и плагины)
не считаются устранёнными этим обновлением. Физический тест давления S Pen
на новых APK не выполнялся.
Проверка каталогов не обнаружила отсутствующих переводов среди проверенных
буквальных вызовов перевода; это не является доказательством отсутствия всех
английских строк во всех редко используемых окнах. Названия продуктов,
форматов, технические идентификаторы и содержимое документов не переводились.
