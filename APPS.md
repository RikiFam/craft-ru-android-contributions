# Русификатор, Android-порты, лаунчер

## 1. Русификатор

[Переводы и отдельное дополнение русской орфографии](russifier/). Пять редакторов используют штатную замену слов; восемь дополнительных панелей копируют исправленный фрагмент для ручной вставки.

## 3. Лаунчер

[Отдельный раздел](launcher/) и [ветка codex/craft-launcher](https://github.com/RikiFam/craft-ru-android-contributions/tree/codex/craft-launcher). Лаунчер отделён от редакторов; для него не заявляется редакторская проверка орфографии.

Ветки — срезы для review, а не самостоятельные сборочные checkout. Общие зависимости указаны в README веток и закреплены по SHA. Полные пакеты содержат инструкции воспроизведения. Это исходники, подготовленные с активной помощью ИИ («вайб-кодинг»), с частичными проверками и явно описанными ограничениями; APK не распространяются.
