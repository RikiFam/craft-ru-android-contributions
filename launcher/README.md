# Лаунчер ArtCraft

Отдельное направление: русский интерфейс лаунчера и экспериментальный Android-хост.

- [Ветка только лаунчера](https://github.com/RikiFam/craft-ru-android-contributions/tree/codex/craft-launcher).
- [Патч русского интерфейса](https://github.com/RikiFam/craft-ru-android-contributions/blob/codex/craft-launcher/russifier/patches/craft-launcher.patch).
- [Android-хост](https://github.com/RikiFam/craft-ru-android-contributions/tree/codex/craft-launcher/android/scripts/artcraft-android/suite/launcher).
- [Точные upstream SHA и происхождение файлов](https://github.com/RikiFam/craft-ru-android-contributions/blob/codex/craft-launcher/sources.json).
- [Инструкции сборки полного Android-пакета](../android/).

Ветка служит для review; общие модули и полные инструкции связаны ссылками. При сборке Android используется App launcher. Необязательная орфография редакторов и модуль прямой печати к лаунчеру не относятся.

Экспериментальная разработка с помощью ИИ. Проверка запуска не означает проверки всех сценариев. Брендинг регулируется upstream docs/brand/LICENSE-brand.txt; публикация исходников не снимает ограничений на распространение изменённого лаунчера. APK и ключей подписи здесь нет.

[Вернуться к программам](../APPS.md).
