# Русский интерфейс ArtCraft

Локальные изменения для установленных версий ArtCraft. Названия приложений,
идентификаторы команд, пользовательские документы и форматы файлов не переводятся.
Перевод редактируется по смыслу и с учётом назначения инструмента; буквальные
кальки и ненужный технический жаргон заменяются понятными формулировками.

- `artcraft_catalog_audit.py`: в проверенных буквальных вызовах локализации девяти
  редакторов нет пропущенных русских ключей; результат — `catalog-audit.json`.
  Проверка учитывает отдельный словарь форматируемых сообщений LightCraft.
- Лаунчер: 51 тест; DeckCraft: 299 прошли, 4 пропущены; SoundCraft: 139 прошли.
  Прогоны UI выполнялись последовательно с доступом к тестовым каталогам
  автосохранения. SoundCraft повторно проверен после последних правок.
- FilmCraft: 19 тестов локализации финального словаря; GridCraft: 9 тестов
  локализации финального словаря. DesignCraft: 7 прошли, 1 отчёт пропущен.
  FigCraft: 20 тестов прошли; затем сокращены подписи стартового экрана.
  LightCraft: 35 тестов прошли. Панели EffectCraft: 6 отдельных Rust-проверок.
- Установленные программы открывались и проверялись по снимкам окон. У WordCraft
  отдельно проверено окно «О программе»; у лаунчера — карточки и подробности.
  Финальные окна FilmCraft, DesignCraft и LightCraft проверены после дополнений.
- Хеши установленных файлов: `installed-builds.json`. Снимки сохранены локально в
  `tmp/artcraft/*-ru.png`; в git не включены.

Пределы проверки: поиск буквальных вызовов не охватывает все динамически
сформированные сообщения, внешние модули и строки, обходящие локализацию.
Каждое редкое окно вручную не проверялось; эти результаты не являются
доказательством стопроцентного покрытия всех возможных состояний интерфейса.
Названия файлов, пользовательских объектов, форматов, команд и сервисов сохранены.

Полный `cargo xtask ci` SoundCraft: форматирование, Clippy, тесты, примеры
из документации, проверка ресурсов и зависимостей между слоями прошли.

Этап WebAssembly не пройден: в окружении отсутствует цель
`wasm32-unknown-unknown`. Это не проверка установленной Windows-сборки.

## Воспроизведение

Исходные коммиты: `patches/sources.json`. Деревья исходников находятся в
`tmp/artcraft/<app>/repo`. Изменения существующих файлов сохранены в `patches/`.
Новые `i18n.rs` и `ru.json` для DeckCraft и SoundCraft создаёт
`scripts/artcraft_localize.py --apply`; нужен tree-sitter в `.local/artcraft-tools`.
Лаунчер обрабатывает `scripts/artcraft_launcher_localize.py`.
Пофайловые исправления DeckCraft/SoundCraft применяет
`scripts/artcraft_file_review.py` (вызывается из `artcraft_localize.py --apply`).
После генерации Rust-файлов выполнить `cargo fmt --all` в каждом репозитории.
Проверенные формулировки из `*-reviewed.tsv` применяет
`scripts/artcraft_review_catalog.py <app>`. Дополнения FilmCraft, CADCraft,
VectorCraft и PdfCraft — `scripts/artcraft_film_extend.py <app>`.
Дополнения FigCraft, DesignCraft, LightCraft и GridCraft —
`scripts/artcraft_native_additions.py <app>`. Подключение пропущенных подписей
стартовых экранов — `scripts/artcraft_home_labels.py`.
Все эти команды запускаются из корня рабочего каталога после применения патчей.
При повторном запуске ключи не дублируются. Панели EffectCraft подключает
`scripts/artcraft_effect_localize.py`; он также создаёт `ru_panels.rs`.
Сборка WordCraft требует `CRAFT_I18N_DIR` на локальный craft-i18n и
`CRAFT_I18N_REQUIRED=1`. Использован зафиксированный в `sources.json` словарь.
Полный CI всех платформ не выполнялся; результаты выше относятся к указанным проверкам.

Сборка из каталога соответствующего репозитория:

```powershell
$env:CARGO_PROFILE_RELEASE_LTO='off'
$env:CARGO_PROFILE_RELEASE_OPT_LEVEL='2'
cargo build --locked --release -p artcraft-launcher
cargo test --locked --release -p artcraft-launcher-ui-egui --lib
```

Для DeckCraft также задать `CRAFT_FONTS_DIR` на checkout `storytold/craft-fonts`
и `CRAFT_FONTS_REQUIRED=1`.

Переводы DeckCraft и SoundCraft используют базовые строки из открытого
`storytold/craft-i18n`, коммит `40cddb99f980576fd9f139fd6ed3b18c16fd81f2`.
Автор исходных словарей: ArtCraft Team и участники проекта, 2026.
Лицензии MIT OR Apache-2.0 приложены. Изменения исходников приложений основаны
на репозиториях `https://github.com/storytold/<app>` с теми же лицензиями.
Шрифты из craft-fonts используют собственные лицензии; см. ATTRIBUTION.md
и файлы лицензий в том репозитории. Бинарные файлы и шрифты здесь не публикуются.

Исходный установленный лаунчер сохранён в
`tmp/artcraft/backups/launcher-0.8.1-original.exe`.
Официальное обновление может заменить локальную русскую сборку.
