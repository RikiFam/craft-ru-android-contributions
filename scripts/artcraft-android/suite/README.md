# Android-перенос ArtCraft

Локальные экспериментальные ARM64-сборки для Samsung Galaxy Tab S7+ (SM-T970,
Android 13). Используют настоящие Rust-движки и интерфейсы из уже переведённых
исходников в `tmp/artcraft/<app>/repo`. Это не официальные Android-релизы.

## Подтверждено на устройстве

- PhotoCraft: запуск русского редактора; пользователь подтвердил перо и силу нажатия.
  Обновлён до preview2 с родным значком.
- ArtCraft Launcher: установка, русские карточки, обнаружение приложений;
  кнопкой «Открыть» из карточки запущен WordCraft (подтверждено активной Activity).
- WordCraft: установка и русское начальное окно.
- CADCraft: установка и русское рабочее окно.
- GridCraft: установка и русское рабочее окно.
- DesignCraft: русское окно, создание A4, сохранение `Макет.designcraft` (4986 байт),
  повторное открытие через файловый браузер; обе вкладки видны на снимке планшета.
- SoundCraft: русское рабочее окно, движок сообщает «звук включён»;
  фактическая запись и воспроизведение ещё не проверены.
- FilmCraft: русское рабочее окно.
- DeckCraft: русское рабочее окно, создание презентации, сохранение
  `Презентация.pptx` (21710 байт).
- GridCraft: дополнительно сохранена `Таблица.xlsx` (4011 байт).
- FigCraft, EffectCraft, VectorCraft: русские рабочие окна после исправлений.
- PdfCraft: русское окно, стандартная кнопка «Открыть» вызывает адаптированный
  выбор файла; тестовая PDF-форма открылась с пятью интерактивными полями.
- LightCraft: русское окно; предупреждение о блокировке каталога устранено,
  в журнале нового процесса нет ошибки блокировки.

На SM-T970 установлены все 13 редакторов и лаунчер (14 отдельных пакетов).
Запуск проверен, но все функции не проверены. Журналы сборки:
`tmp/artcraft/android/<app>-build.log`. Снимки планшета там же, не в git.
Контрольные суммы и проверки значков собранных APK записаны в `verification.json`;
PhotoCraft имеет отдельный отчёт `../verification.json`.

## Сборка

Из корня: `./scripts/artcraft-android/build-suite.ps1 -App wordcraft`.
`-PackageOnly` упаковывает уже собранную библиотеку (не проверяет актуальность кода).
Общий Android target и ключ подписи используются из первой сборки PhotoCraft.
Для FilmCraft, EffectCraft и PdfCraft сборщик применяет `suite/patch_android.py`:
он оставляет accesskit настольным платформам, где тот поддерживается.
Для PdfCraft также применяет `suite/prepare_pdf.py`: локальная копия rfd 0.17.2
получает Android-очередь асинхронных запросов выбора файлов. Исходная rfd должна
быть предварительно загружена в Cargo registry. Системный буфер изображений
arboard остаётся только на поддерживаемых настольных платформах.

У каждого APK отдельный package `ai.storyteller.<app>.ru` (лаунчер:
`ai.storyteller.artcraftlauncher.ru`), NativeActivity, родной значок и русская подпись.
Ресурсы значков копируются при упаковке, без перерисовки. Их источники и лицензии
указаны в `ATTRIBUTION.md`.

Лаунчер определяет установленность через Android PackageManager и открывает
приложения через Intent. Он не скачивает Windows-релизы, не предлагает их как
обновления Android и не выполняет самостоятельную установку APK.

Рабочие файлы первой версии находятся в `Android/media/ai.storyteller.<app>.ru`.
Каталог LightCraft хранится во внутренней папке приложения. `std::fs::File::try_lock`
на Android возвращал `not supported`; `prepare_light.py` подключает безопасный
`rustix::fs::flock` только для Android. Настольные платформы используют прежний код.
Удаление приложения удаляет каталог.
В CADCraft, GridCraft и следующих адаптерах верхняя строка «Файлы на планшете»
обходит настольные системные диалоги. WordCraft использует встроенный файловый
браузер. Системный выбор документов Android пока не подключён.

Проверка запуска не подтверждает сохранение, все форматы импорта, звук, аппаратные
кодеки, экранную клавиатуру и восстановление после выгрузки процесса. Эти проверки
нужно отмечать отдельно, по фактическим результатам.

Ограничения preview: системный выбор документов Android и общая галерея не подключены;
передавайте файлы в папку соответствующего приложения. Настольные плагины, печать,
микрофон SoundCraft и мультимедийные службы FilmCraft требуют отдельной адаптации/проверки.
Остались английские имена новых документов/страниц и отдельные подписи/шаблоны
(например, `Untitled`, `Page 1`, `No photos`): полной русификацией это пока не считается.
Настройка тайм-аута экрана после проверки восстановлена на исходные 60000 мс.
