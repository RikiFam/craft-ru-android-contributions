# PhotoCraft на Galaxy Tab S7+: экспериментальная нативная сборка

Цель: личная APK с русским интерфейсом для Samsung Galaxy Tab S7+, ARM64,
Android 10 или новее. Это отдельный Android-запуск редактора PhotoCraft 0.16.0,
а не Windows-программа в эмуляторе и не страница сайта в оболочке.

Исходный коммит PhotoCraft: `b1794c6e0608ccfc887213dcf58398977c5cb75e`.
Используется локальный checkout `tmp/artcraft/photocraft/repo` с русским
словарём и исправлениями из `scripts/artcraft-russian`.
Движок, обработка изображений и интерфейс взяты из этого checkout.

## Сборка

Нужны Rust с `aarch64-linux-android`, Android NDK r27d, Android SDK
с платформой android-35 и Build Tools 35.0.0, JDK 17.
`build.ps1` принимает пути `-Sdk`, `-Ndk`, `-Jdk`; значения по умолчанию
соответствуют имеющимся инструментам на этом компьютере.
Для инструментов NDK с ошибкой обработки кириллицы используется проверенная
ссылка `E:\Codex\ArtCraftAndroidLink` на каталог результатов. Адаптер
`android-link.rs` переводит только пути аргументов компоновщика и response-файлов
на эту ссылку; исходники, русский интерфейс и расположение файлов не меняются.
Существующая чужая папка на месте ссылки не заменяется.

`apply_source_patch.py` разделяет функции eframe: для Android NativeActivity
отключает несовместимый accesskit, а для прежних платформ сохраняет его.
Установленные Windows-программы не заменяются.

Сборка: `powershell -ExecutionPolicy Bypass -File scripts/artcraft-android/build.ps1`.
APK и личный ключ подписи находятся в `tmp/artcraft/android`, не в git.
Ключ предварительной сборки использует стандартный пароль `android`,
не предназначен для публикации и должен сохраняться для обновления этой APK.
В APK только `arm64-v8a`; разрешений на сеть и полный доступ к хранилищу нет.

## Работа с файлами в первой версии

Рабочая папка:
`Android/media/ai.storyteller.photocraft.ru` во внутренней памяти планшета.
Файлы нужно положить туда через «Мои файлы» или USB, затем открыть из редактора.
Диалог показывает подпапки и позволяет сохранить результат с выбранным расширением.
Системный Storage Access Framework, облачные диски и получение файлов через
Android «Поделиться» пока не подключены. Если общая рабочая папка недоступна,
программа использует внутреннюю папку приложения; её путь виден в диалоге.

Подключены настройки, атомарная запись файлов и механизм восстановления
автосохранений PhotoCraft. Удаление приложения удаляет его личные данные.
Перед обновлением/удалением сохраняйте нужные документы отдельно.

## Проверки

- Проверка Android ARM64 (`cargo check`) и Clippy с `-D warnings` прошли.
- Проверка настольной локализации: 51 тест прошёл, ошибок нет.
- Тесты файловых операций: русское имя, запрет пути вместо имени,
  полная замена файла, отсутствие временных файлов и перехват сбоя декодера — 3 прошли.
- APK установлен и запущен на Samsung Galaxy Tab S7+ (SM-T970), Android 13.
  Холодный запуск NativeActivity успешен, процесс продолжает работать;
  снимок экрана подтвердил рабочее окно редактора на русском языке.
  В проверенном фрагменте журнала ошибок запуска нет.
  Редактирование и сохранение на устройстве пока не проверены.
- S Pen, жесты, экранная клавиатура, поворот экрана и восстановление после
  выгрузки Android требуют проверки на устройстве. Не считать их подтверждёнными.

APK: библиотека ELF64/AArch64, экспортированы `android_main` и
`ANativeActivity_onCreate`. Все динамические зависимости — системные библиотеки
Android. Сегменты ELF выровнены на 16 КБ. Манифест прочитан обратно из APK:
пакет `ai.storyteller.photocraft.ru`, minSdk 29, targetSdk 35, NativeActivity, русская подпись.
Подпись APK v3 проверена `apksigner`; выравнивание пакета — `zipalign`.

Android-вход построен по публичному примеру eframe 0.36.2:
https://github.com/emilk/egui/tree/0.36.2/examples/hello_android
и использует тот же NativeActivity backend. Единственный `unsafe`-атрибут
экспортирует обязательный символ `android_main`; unsafe-блоков в оболочке нет.
