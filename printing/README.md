# Печать и настройки принтера — экспериментальные исходники

Отдельный снимок WordCraft: Windows printer preferences/UserPrintTicket и кнопка
входа в системные параметры Epson на Android. Пакет содержит только WordCraft,
его необходимые общие зависимости и инструменты печати, а не весь набор редакторов.
Текущая прямая Wi-Fi-печать, вкладка обслуживания Epson, проверка дюз и очистка
из продолжающегося исходного чата в этот снимок НЕ входят.

После `python prepare_sources.py` запустите
`python scripts/artcraft-printing/prepare.py`, затем соберите Windows WordCraft
по upstream README в `tmp/artcraft/wordcraft/repo`. Закреплённый print-vendor
уже загружен: личный Cargo-кэш не нужен. Подготовка не отправляет задания на принтер.
Полный патч WordCraft также содержит базовые Android-адаптации; для Android-сборки
нужны хосты из отдельного пакета android. Для переноса на него используйте prepare.py
после подготовки обоих пакетов, предварительно скопировав `scripts/artcraft-printing`
и закреплённый `tmp/artcraft/print-vendor` в папку android. Не применяйте полный патч
WordCraft повторно поверх Android-патча.

В исходном чате проверены сборки Windows/Android, реальные окна и чтение/валидация
PrintTicket без спулинга. Новый физический отпечаток этим тестом не подтверждён.
Драйверные свойства меняют настройки текущего пользователя Windows, включая другие
программы. Качество драйвера не снимает предел растеризации 300 DPI / 4096 px.
Общий CI остановился на прежней ошибке Clippy; Clippy изменённых компонентов прошёл.
Подробный исторический отчёт: `scripts/artcraft-printing/README.md`; упомянутые там
локальные логи, verification.json и резервные копии не публикуются.

## Воспроизведение и лицензии

Распакуйте этот пакет в отдельную новую папку. Установите Git, Python 3 и Rust.
Запустите `python prepare_sources.py` из папки пакета: он получает точные upstream SHA
и применяет патчи с проверкой. Существующие каталоги исходников не перезаписываются.
SHA и SHA256 патчей находятся в `sources.json`. Патчи уже включают нужные зависимости;
не накладывайте архивные патчи повторно. Сохраняются MIT/Apache-2.0 и лицензии upstream.
Брендинг Launcher ограничен `docs/brand/LICENSE-brand.txt`: для распространения
модифицированного лаунчера нужны замена брендинга и имени либо разрешение авторов.
Это экспериментальные исходники, не официальный выпуск. APK и ключей подписи нет.
Независимая полная пересборка этих отдельных пакетов не выполнялась.
