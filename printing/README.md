# Печать и обслуживание принтера — экспериментальные исходники

Обновление d49897d: прямая Wi-Fi-печать на Epson L3250 и три пункта сервиса:
проверка дюз, обычная очистка головки, состояние Epson. Отдельный модуль для девяти
редакторов. APK, ключи, личный адрес принтера и снятые с устройства данные не включены.
Исходный Android-порт и русификатор остаются отдельными пакетами.

## Воспроизведение

1. Распакуйте отдельный Android ZIP снимка 93708b2 в новую папку, например `../android`.
2. Из этой папки printing выполните `python apply_android_overlay.py ../android`.
   Скрипт заранее сверяет SHA256 всех заменяемых файлов и отказывается менять чужие
   правки. Допустимо повторное применение уже установленного overlay. Адрес принтера
   в пользовательском диалоге пуст: его вводит сам пользователь.
3. Выполните `python prepare_sources.py` в Android-пакете, следуйте его инструкциям
   полной сборки с собственными путями SDK/JDK/NDK. Не используйте PackageOnly, если
   у вас нет ранее собранной native-библиотеки. Сначала собирается PhotoCraft.
4. Для новых подсказок WordCraft сначала подготовьте этот printing-пакет командой
   `python prepare_sources.py`, скопируйте `scripts/artcraft-printing` и закреплённый
   `tmp/artcraft/print-vendor` из printing в Android-пакет. Там выполните
   `python scripts/artcraft-printing/prepare.py` перед полной сборкой WordCraft.
   Для Windows выполняются те же prepare_sources.py/prepare.py внутри printing,
   затем штатная сборка WordCraft. Подготовка не печатает и не очищает головку.

Java/DEX-тесты без принтера: из Android-пакета запустите
`./scripts/artcraft-android/platform/tests/build-probes.ps1 -Sdk <SDK> -Jdk <JDK>`.
Ручной тестовый Activity может отправлять задания только по явным действиям;
не запускайте его ради проверки сборки. PrinterProbe с --test-cancel создаёт пустое
задание и отменяет его. Это не входит в автоматическую подготовку исходников.

## Проверки и ограничения

В исходном чате все девять приложений установлены, сверены версии/хеши. Пользователь
подтвердил один физический отпечаток и один лист проверки дюз на общем модуле.
Из каждого редактора отдельно лист не печатался. Последний интерфейс сервиса проверен
в WordCraft. Обычная очистка реализована, но физически не запускалась. Сетевое принятие
команды не считается физическим завершением; переход статуса при проверке дюз не
наблюдался. Поддержка обслуживания ограничена L3250.

Прямая печать использует PWG 360 dpi; прежний системный путь ограничен 300 DPI/4096 px.
Высокое качество обычной A4 через IPP принтер отвергает; высокое на глянцевой 10x15
принималось. Нет автоматического дуплекса, полноценного мастера ручного дуплекса,
печати без полей, произвольной бумаги, калибровки и усиленной очистки.
IPPS использует доверие первому контакту и закрепление сертификата адреса; SNMP/LPR
обслуживания не шифруются. Передача не восстанавливается после завершения процесса.
Независимая полная Rust/Android-пересборка этого пакета не выполнялась.

Исходники получены только из коммита d49897d8fab1e526e8a49d4e45f81eb36b370079.
Базовые WordCraft/upstream SHA остались в sources.json; overlay и хеши в
android-overlay/manifest.json. Исторические отчёты ANDROID-DIRECT.md и
ANDROID-MAINTENANCE.md в scripts/artcraft-printing описывают свои версии; сырые
локальные verification.json, сетевые дампы и резервные APK не распространяются.
