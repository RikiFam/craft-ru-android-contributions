# ArtCraft: русификатор, порты, лаунчер

Неофициальные экспериментальные исходники, разработанные с активной помощью ИИ («вайб-кодинг»). Работа идёт итеративно: изменения, сборки, целевые тесты и выборочные проверки на Windows/Android. Подтверждённые результаты и ограничения описаны в пакетах. Независимая полная пересборка не проведена.

| Главный раздел | Что внутри |
|---|---|
| [Русификатор](russifier/) | Перевод интерфейса и необязательная русская орфография |
| [Порты на Android](android/) | Порты редакторов, ввод, работа с файлами; [необязательный вывод на печать](android/printing/) |
| [Лаунчер](launcher/) | Отдельная ветка лаунчера, перевод и Android-хост |

[Разбивка по программам — 13 редакторов и лаунчер](APPS.md). Ветки содержат материалы конкретной программы для review; общие модули связаны ссылками на точный снимок. Для сборки используются полные пакеты и инструкции.
