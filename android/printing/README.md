# Вывод на печать — необязательное дополнение портов

Этот модуль пригодится тем, кто печатает документы с планшета. Он не обязателен для использования остальных функций редакторов.

- [Исходники, инструкции, лицензии и подробные ограничения](../../printing/).
- [Отдельный архив исходников](../../downloads/printing-d49897d.zip).
- [Ветки отдельных программ](../../APPS.md).

Общий модуль интегрирован в WordCraft, GridCraft, DeckCraft, CADCraft, DesignCraft, VectorCraft, PdfCraft, LightCraft и PhotoCraft. Системная печать Android и прямая Wi-Fi-печать Epson — разные пути. Поддержка обслуживания ограничена Epson L3250.

На общем модуле подтверждены физический отпечаток и лист проверки дюз. Обычная очистка головки физически не проверялась; каждый редактор отдельно не проходил проверку печатью листа. Состояние команды по сети не гарантирует физический результат.

В архиве также сохранены отдельные изменения настроек Windows-драйвера WordCraft: их область применения обозначена в инструкции. Существующие пути пакета printing сохранены для совместимости сборочных инструкций; в навигации это подраздел Android-портов.

Экспериментальные исходники, без APK. [К портам](../).
