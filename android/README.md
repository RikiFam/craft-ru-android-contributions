# Порт ArtCraft на Android — экспериментальные исходники

ARM64 Rust/egui-хосты, сборочные скрипты, Android document picker, системный мост
печати и исправления ввода WordCraft. Русские переводы включены как зависимость,
чтобы пакет можно было собрать отдельно. Доработки свойств Epson/Windows-драйвера
и новая прямая Wi-Fi-печать сюда не включены: это отдельный раздел `printing`.
Системный PrintManager остаётся частью платформенного порта.

После `python prepare_sources.py`: установите JDK 17, Android SDK 35, Build Tools
35.0.0, NDK r27d; выполните `rustup target add aarch64-linux-android`.
Сначала соберите PhotoCraft (создаётся локальный ключ разработки):

```powershell
./scripts/artcraft-android/build.ps1 -Sdk C:/Android/Sdk -Ndk C:/Android/ndk-r27d -Jdk C:/Java/jdk-17 -LinkAlias C:/CraftAndroidBuild
./scripts/artcraft-android/build-suite.ps1 -App wordcraft -Sdk C:/Android/Sdk -Ndk C:/Android/ndk-r27d -Jdk C:/Java/jdk-17 -LinkAlias C:/CraftAndroidBuild
```

LinkAlias должен быть свободным ASCII-путём. PdfCraft требует rfd 0.17.2 в Cargo
registry перед подготовкой. Скрипты локально создают тестовые APK; они не опубликованы.

Проверки исходного чата: запуск/версии всех 14 пакетов предыдущего обновления;
выбранные open/save-сценарии, вход в системную печать, русский экранный ввод и resume.
Последующие изменения ввода пересобирались только для WordCraft. Полная функциональная
проверка, физический двухпальцевый жест и длительная ANR-стабильность не подтверждены.
Растеризация печати ограничена 300 DPI / 4096 px. Исторические отчёты не сертифицируют
все текущие изменения. См. `scripts/artcraft-android/platform/VERIFICATION.md`.

## Воспроизведение и лицензии

Распакуйте этот пакет в отдельную новую папку. Установите Git, Python 3 и Rust.
Запустите `python prepare_sources.py` из папки пакета: он получает точные upstream SHA
и применяет патчи с проверкой. Существующие каталоги исходников не перезаписываются.
SHA и SHA256 патчей находятся в `sources.json`. Патчи уже включают нужные зависимости;
не накладывайте архивные патчи повторно. Сохраняются MIT/Apache-2.0 и лицензии upstream.
Брендинг Launcher ограничен `docs/brand/LICENSE-brand.txt`: для распространения
модифицированного лаунчера нужны замена брендинга и имени либо разрешение авторов.
Это экспериментальные исходники, не официальный выпуск. APK и ключей подписи нет.
Независимая полная пересборка этих отдельных пакетов не выполнялась.
