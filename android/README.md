# Порт ArtCraft на Android — экспериментальные исходники

ARM64 Rust/egui-хосты, сборочные скрипты, Android document picker, системный мост
печати и исправления ввода WordCraft. Русские переводы включены как зависимость,
чтобы пакет можно было собрать отдельно. Доработки свойств Epson/Windows-драйвера
и новая прямая Wi-Fi-печать сюда не включены: это отдельный раздел `printing`.
Системный PrintManager остаётся частью платформенного порта.

После `python prepare_sources.py`: установите JDK 17, Android SDK 35, Build Tools
35.0.0, NDK r27d; выполните `rustup target add aarch64-linux-android`.
Сначала соберите PhotoCraft (создаётся локальный ключ разработки):

```powershell
./scripts/artcraft-android/build.ps1 -Sdk $env:ANDROID_HOME -Ndk $env:ANDROID_NDK_HOME -Jdk $env:JAVA_HOME -LinkAlias $env:ARTCRAFT_BUILD_ALIAS
./scripts/artcraft-android/build-suite.ps1 -App wordcraft -Sdk $env:ANDROID_HOME -Ndk $env:ANDROID_NDK_HOME -Jdk $env:JAVA_HOME -LinkAlias $env:ARTCRAFT_BUILD_ALIAS
```

LinkAlias должен быть свободным ASCII-путём. PdfCraft требует rfd 0.17.2 в Cargo
registry перед подготовкой. Скрипты локально создают тестовые APK; они не опубликованы.

Проверки исходного чата: запуск/версии всех 14 пакетов предыдущего обновления;
выбранные open/save-сценарии, вход в системную печать, русский экранный ввод и resume.
Последующие изменения ввода пересобирались только для WordCraft. Полная функциональная
проверка, физический двухпальцевый жест и длительная ANR-стабильность не подтверждены.
Растеризация печати ограничена 300 DPI / 4096 px. Исторические отчёты не сертифицируют
все текущие изменения. См. `scripts/artcraft-android/platform/VERIFICATION.md`.

## Воспроизведение и лицензии

Распакуйте этот пакет в отдельную новую папку. Установите Git, Python 3 и Rust.
Запустите `python prepare_sources.py` из папки пакета: он получает точные upstream SHA
и применяет патчи с проверкой. Существующие каталоги исходников не перезаписываются.
SHA и SHA256 патчей находятся в `sources.json`. Патчи уже включают нужные зависимости;
не накладывайте архивные патчи повторно. Сохраняются MIT/Apache-2.0 и лицензии upstream.
Брендинг Launcher ограничен `docs/brand/LICENSE-brand.txt`: для распространения
модифицированного лаунчера нужны замена брендинга и имени либо разрешение авторов.
Это экспериментальные исходники, не официальный выпуск. APK и ключей подписи нет.
Независимая полная пересборка этих отдельных пакетов не выполнялась.

## Необязательная русская орфография (69ae9d8)

Распакуйте рядом пакеты russifier-69ae9d8 и printing-d49897d. На свежий Android-пакет
сначала примените `python ../printing/apply_android_overlay.py .`.
Затем выполните `python apply_spelling_overlay.py ../russifier` из папки Android.
Подготовьте базовые исходники `python prepare_sources.py`, после этого
`python prepare_spelling.py`; выполните полную сборку, как описано выше.
Если исходники уже подготовлены, не запускайте prepare_sources.py повторно.
Не используйте PackageOnly для внедрения новых Rust-изменений орфографии.
Упаковка включает лицензионное уведомление словаря. APK и ключи не публикуются.

Интеграция требует отдельного printing overlay d49897d: это явная зависимость
общего CraftActivity, его функциональность не скопирована в русификатор.
В пяти редакторах работает штатная замена, в восьми исправленный фрагмент копируется
для ручной вставки; Android clipboard-мост добавлен этим overlay. Полный финальный
обход планшета и общий CI не завершены; см. verification.json дополнения russifier.

## DeX и системные жесты Android — e706b13

Для нового каталога сначала примените printing overlay d49897d и spelling overlay
69ae9d8 по инструкциям выше, затем `python apply_dex_overlay.py`. Подготовьте исходники
через prepare_sources.py (один раз) и prepare_spelling.py. Выполните полную сборку
нужных редакторов/лаунчера без PackageOnly: изменяется Rust-backend winit.
prepare_input.py берёт точный winit SHA из tmp/artcraft/android/winit-source,
загруженного prepare_sources.py; личный Cargo-кэш не используется и не изменяется.
Проверяемые хеши исходных и новых файлов — dex-overlay/manifest.json.

Общий backend передаёт потоки мыши/тачпада штатным Android GestureDetector и
ScaleGestureDetector; обычный сенсорный ввод сохраняется. Child SurfaceView оставляет
системе настоящую панель DeX: перемещение, изменение размера, сворачивание/разворачивание.

Исходный чат подтвердил установку, запуск и системную панель во всех 14 приложениях.
Пользователь подтвердил жесты в WordCraft; каждый жест вручную во всех редакторах
не проверялся. Автотесты SDK-детекторов запускались на устройстве в исходном чате.
Это экспериментальный исходный снимок, не гарантия всех устройств/версий Android.
Независимая полная Rust-пересборка и новый тест на планшете при экспорте не проводились.

Локальная проверка компиляции: platform/tests/run-touchpad-tests.ps1 с параметрами
-Sdk и -Jdk (путь внутри scripts/artcraft-android). Только явный -RunOnDevice с -Adb
и -Serial запускает тесты на вашем устройстве. Скрипты установки на авторское устройство
и сырые журналы исключены. APK, ключи и идентификатор личного устройства не включены.
Подробности: dex-overlay/scripts/artcraft-android/platform/INPUT-DEX.md.
